# Bundled multilingual fonts

The font stack preserves the game's Alagard for English and the supplied Alagard Unicode for European-language catalogs. Other text and missing Alagard glyphs now use **Fusion Bold Pixel**, with separate Simplified Chinese, Traditional Chinese, Japanese, Korean and Latin faces. All current catalog characters are covered by Alagard or Fusion; Noto remains last in the stack solely for unsupported future characters, such as polytonic Greek and Vietnamese accents. All font files are served from this folder; there are no runtime requests to external font services.

Fusion uses each locale's regional face directly. The 12px proportional square outline TTFs supplied by FontPixel scale in browsers and Electron; bitmap-only TTFs were not used. The files are unmodified from those downloads. At text sizes divisible by 12, their design aligns to whole pixels; other sizes retain the square-pixel shape but can be interpolated. Noto Sans CJK's final fallback uses its localized glyph forms when supported by language tags.

The CSS declares these fonts once in `fonts.css`. A Fusion face is about 6 MB and loads when used. Noto Sans CJK is about 16 MB and loads only if needed for missing glyphs in its declared Unicode ranges. Additional scripts such as Arabic or Thai need separately configured fonts; this bundle does not claim all Unicode coverage.

The supplied Alagard Unicode font is unchanged. Its original `license.txt` and `readme.txt` accompany it as required by the archive notice. Credit: Alagard-12px-unicode by iosoftware, licensed under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). Font attribution also appears in the game's end credits.

Fusion Bold Pixel by TakWolf is licensed under SIL OFL 1.1. Its copyright/license notice accompanies the fonts, and attribution appears in the end credits. FontPixel generated the provided square outlines from the upstream bitmap design; we have not rebuilt or edited them.

Pixel Art Controller Fonts are kept separate from normal text. `ControllerGlyphs.js` maps standard physical button indices to the pack's actual glyph codes; mixed text runs keep keyboard keys and translated words in Alagard/Fusion. PlayStation uses the supplied `DualShockMod.ttf` without altering its bytes. Square is `s` (the former `v` mapping was a Share glyph). PS4 uses `r` for SH/Share and `q` for OP/Options; DualSense uses `p` for Create and `o` for Options. Automatic detection uses controller names and Sony's PS5/Edge product IDs; Controls also offers explicit PlayStation 4 and DualSense choices. Existing saved PlayStation preferences select PS4. Nintendo uses compatible Xbox face-button, shoulder, stick and D-pad icons; ZL/ZR and plus/minus stay textual because this pack does not provide them. Raw/unknown devices, analog-axis bindings and fonts that have not loaded keep readable text. The original `Xbox.ttf`, reference `DualShock.ttf` and archive license notice are unchanged. Attribution is included in the credits even though CC0 does not require it.

Use `controller-menu-preview.html` to inspect the actual Controls renderer with simulated layouts and languages, without changing saved settings. `controller-font-preview.html` lists the individual glyph codes.

Use `font-preview.html` for visual inspection and `python tools/check-font.py` to check representative characters and every character actually shipped in the new translations against the pixel-font character maps. This check fails if a current catalog would require Noto. Noto fonts were downloaded on 2026-10-11 and Fusion on 2026-10-12; see `manifest.json` for source URLs and SHA-256 checksums.
